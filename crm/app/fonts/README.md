# Знак рубля из Inter (`inter-ruble.ttf`)

Один знак «₽» (U+20BD) из переменного Inter (версия 4.001, та же, что отдаёт Google Fonts), 2,3 КБ.
Зачем он нужен — комментарий у `ruble` в `app/layout.tsx`: в Inter от Google этот знак лежит в файле
`latin-ext` на 85 КБ.

Лицензия шрифта — SIL Open Font License 1.1, вырезка подмножества разрешена. Её текст и уведомление об авторских правах
(Inter Project Authors) лежат рядом, в `OFL.txt`: лицензия требует, чтобы они шли вместе с распространяемым шрифтом,
поэтому файл не удалять и держать в одной папке со шрифтом, а при замене шрифта — обновить вместе с ним.
То же уведомление об авторских правах записано и в самом файле шрифта (таблица имён, запись 0): оно едет с ним к посетителю.

## Как получить заново

Обычный путь, на любой машине (нужен `pip install fonttools brotli`):

```
pyftsubset latin-ext.woff2 --unicodes=U+20BD --layout-features='*' --output-file=inter-ruble.ttf
```

`latin-ext.woff2` — файл Inter с диапазоном `U+100-2BA … U+20AD-20C4` из `.next/static/media` готовой сборки
(в `@font-face` с таким `unicode-range`). Файл в репозитории получен так: woff2 разобран системным CoreText
(в sfnt), затем `hb-subset --unicodes=U+20BD`. Проверка: `hb-view` на насыщенности 400, 600 и 700 даёт
одинаковые картинки у исходного шрифта и у вырезки.

Менять шрифт сайта (другая версия Inter) — значит вырезать знак заново из нового файла.
