# Разделение кабинетов — тестовый стенд

По решению владельца от 30.10.2026 кабинет работодателя находится на студенческой платформе: профиль, отклики, вакансии, кандидаты и сообщения.

В CRM остаётся кабинет клиента агентства: его заявки на подбор, кандидаты агентства, сообщения, документы, метрики и обзоры. Записи Client и User не удаляются и не переписываются.

Пункт `/students` удалён из клиентского меню. Старые страницы показывают ссылку на студенческую платформу; действие `students.enterAsClient` закрыто для всех клиентских ролей, включая старые server actions. Агентские разделы модерации и служебный обмен сохранены. Студенческая сессия больше не выдаёт билет для входа в CRM.

Существующие вакансии агентства с crmId по-прежнему управляются агентством. Новые вакансии работодатель создаёт в своём кабинете платформы. Эта правка не меняет владельцев вакансий и данные клиентов.
