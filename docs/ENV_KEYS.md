# Справочник ключей (переменных окружения)

Здесь **только имена, назначение и где задаётся — без значений**. Сами значения лежат в `.env`-файлах рабочих папок и в настройках проектов на Vercel. Этот файл можно хранить в репозитории.

Где задаётся:
- **Локально**: `fattakhov-hr-platform-main/.env` (CRM), `platform_for_students/.env` (платформа). Файлы в git не попадают.
- **Боевое**: Vercel → проект → Settings → Environment Variables. CRM — `fattakhov-hr-agency-a7o3`, платформа — `fattakhov-hr-agency-96ge`.

## Общие между системами (значения должны совпадать)

| Ключ | Где нужен | Назначение |
|---|---|---|
| `CRM_SERVICE_SECRET` | CRM и платформа | Служебный Bearer: вызовы CRM → платформа (`/api/service/*`) и webhook платформа → CRM. Не короче 32 символов. |
| `STUDENTS_SSO_SECRET` | CRM и платформа | Подпись билета входа сотрудника CRM на студенческую платформу. |
| `CRM_ENTRY_SECRET` | CRM и платформа | Подпись билета входа клиента со студенческой платформы в CRM. |

Смена любого из трёх ломает соответствующую связку, пока значение не обновлено в обеих системах и оба проекта не выкачены заново.

## CRM

| Ключ | Обязателен на проде | Назначение |
|---|---|---|
| `DATABASE_URL` | да | База CRM. |
| `DATABASE_URL_TEST` | только для тестов | Отдельная база для `vitest`; никогда не боевая. |
| `AUTH_SECRET` | да | Подпись сессий, ссылок на файлы и лент календаря. Смена разлогинит всех и отзовёт ссылки календаря. |
| `AUTH_URL` | да | Публичный адрес CRM для Auth.js. |
| `STUDENTS_URL` | да | Адрес студенческой платформы (ссылки и служебные вызовы). Без него кнопки «Студентам» скрыты. |
| `TOTP_ENCRYPTION_KEY` | нет | Шифрует секреты 2FA в базе. Не короче 32 символов. После включения не менять: иначе люди с 2FA войдут только по кодам восстановления. Без ключа — хранятся как раньше. |
| `SMTP_URL`, `SMTP_FROM` | да | Почта: приглашения, сброс пароля. Без них письма уходят в лог. |
| `S3_ENDPOINT`, `S3_REGION`, `S3_BUCKET`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY` | да | Хранилище файлов (резюме, договоры, логотипы). Без S3 файлы пропадают при перезапуске. |
| `FILE_STORAGE_PATH` | нет | Папка файлов без S3 (только разработка). |
| `TELEGRAM_BOT_TOKEN` | нет | Уведомления в Telegram. |
| `APP_URL`, `SITE_URL` | по ситуации | Публичный адрес для ссылок в письмах и календаре. |
| `ALLOW_DRAFT_CONSENT` | нет | Временно разрешает черновой текст согласия; убрать, когда юридический текст утверждён. |
| `USE_TEST_DB`, `WIPE_DEV_DB`, `SEED_PRODUCTION` | никогда | Только для разработки. |

## Студенческая платформа

| Ключ | Обязателен на проде | Назначение |
|---|---|---|
| `DATABASE_URL` | да | База платформы (на проде — роль без прав менять схему). |
| `DIRECT_DATABASE_URL` | да | Строка для миграций (администратор базы). |
| `PII_ENCRYPTION_KEY` | да | Мастер-ключ шифрования персональных данных студентов. **Потеря = потеря ФИО, почт и телефонов.** Хранить копию в надёжном месте, не менять без `npm run` скрипта ротации (`scripts/rotate-pii-key.ts`). |
| `PII_ENCRYPTION_KEY_OLD` | только при ротации | Прежний ключ на время перешифровки. |
| `JWT_SECRET` | да | Подпись сессий. Смена разлогинит всех. |
| `APP_URL` | да | Публичный адрес платформы. |
| `AGENCY_SITE_URL` | да | Адрес сайта агентства/CRM для ссылок. |
| `SMTP_URL`, `SMTP_FROM` | да | Почта: коды подтверждения, сброс пароля, уведомления. |
| `S3_ENDPOINT`, `S3_REGION`, `S3_BUCKET`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY` | да | Хранилище фото, резюме, справок, картинок компаний. |
| `CRON_SECRET` | желательно | Защита вызова ежедневных напоминаний (`/api/cron/notify`). На проде пока не задан. |
| `REDIS_URL` | нет | Не нужен: общий счётчик лимитов теперь хранится в базе. |
| `UPLOAD_DIR` | нет | Папка загрузок без S3 (разработка). |
| `CRM_SYNC_URL`, `CRM_SYNC_TOKEN` | нет | Устаревшая синхронизация, пустые. |
| `ALLOW_REMOTE_SEED` | никогда на проде | Разрешает `db:seed` не на локальной базе; без неё seed откажется. |
| `SMOKE_URL` | только тесты | Адрес сервера для `npm run smoke`. |

## Служебные переменные Vercel (создаются платформой)

`VERCEL*`, `TURBO_*`, `NX_DAEMON`, `POSTGRES_*`, `PG*`, `NEON_*`, `VITE_NEON_AUTH_URL`, `DATABASE_URL_UNPOOLED`, `VERCEL_OIDC_TOKEN` — не задаются вручную. Файл `.env.production.local` — это выгрузка `vercel env pull` с боевыми значениями: держать вне репозитория и не пересылать.

## Правила обращения

1. Значения не хранить в репозитории, в чатах и в синхронизируемых папках; файл `prod-secrets.txt` рядом с проектами лучше перенести в менеджер паролей.
2. Ключи `PII_ENCRYPTION_KEY` и `TOTP_ENCRYPTION_KEY` потерять нельзя и менять без процедуры нельзя.
3. Локальные и боевые значения разные; к боевой базе с локальной машины не подключаться.
