Что сделано

Дизайн-система. Палитра из брифа (#F8F8F8 / #000 / #2F3337 / #546E88) развёрнута в холодные шкалы — чистый серый рядом с фирменным графитом выглядит грязным. Логотип взят из брендбука соседнего проекта (реальный изо-куб F/H/R), а не воспроизведён в SVG. Атмосфера: холодное свечение сверху задаёт источник света, плёночное зерно 5% убирает эффект «выключенного экрана».

Физика свайпа (SwipeCard.tsx). Наклон пропорционален смещению и домножен на точку захвата — у края карточка разворачивается сильнее, чем в центре. Решение засчитывается по расстоянию (112 px) или по скорости (520 px/с): только по расстоянию не срабатывает быстрый флик, только по скорости — медленное уверенное перетаскивание. Вправо — зелёная кромка, влево — затемнение; следующая карточка выезжает снизу.

Экраны. Лендинг с живой колодой (её можно свайпать прямо на витрине), мастер регистрации из 6 шагов, лента, отклики с воронкой, пропущенные с возвратом, кабинет работодателя, панель HR-менеджера.

Безопасность. AES-256-GCM для ПДн + HKDF-подключи + слепой HMAC-индекс для поиска по зашифрованной почте; JWT в httpOnly-куке через jose (работает и в middleware на edge); bcrypt cost 12; скользящее окно лимитов на ZSET; журнал аудита; согласие на ПДн с версией, датой и IP. Разграничение в два рубежа: middleware по URL + guards в каждом роуте.

Три решения, которые стоит знать

Демо-режим. У вас Postgres настроен, но остановлен. Без DATABASE_URL приложение поднимает хранилище в памяти на тех же фикстурах, что и настоящая база — чтобы продукт можно было открыть сразу. В production такой подмены нет: падает на старте с внятной ошибкой. Контракт DataStore один, реализации две.

Производительность. Я убрал filter: blur() из анимаций страницы и списков — это самая дорогая анимация, и она оставляет после себя blur(0px), навсегда выносящий элемент в отдельный слой. Расфокус остался там, где движется один элемент (шаги мастера). backdrop-filter — только там, где сквозь него что-то видно; строки списков используют матовую .surface, на чёрном фоне неотличимую.

Цвет в статистике. Валидатор палитры показал, что два соседних оттенка монохромного бренда неразличимы для дальтоника (ΔE 11.3 при пороге 15). Поэтому доля свайпов вправо нарисована одним акцентом на нейтральной дорожке, а не двумя цветными сегментами.

Проверено

Все экраны просмотрены глазами на десктопе; на 375px проверено отсутствие горизонтального переполнения — нашёл и починил три места, где элементы грида распирали страницу.
